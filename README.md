# CS 12-Week Learning Journey

A 12-week journey to rebuild my computer science foundations, improve independent programming skills, and explore game development.

## Goals

- Rebuild C++ programming fundamentals.
- Strengthen data structures and algorithms.
- Develop independent problem-solving and debugging skills.
- Learn Python fundamentals.
- Explore game programming and build a small playable game.
- Practice Git, GitHub, and technical documentation.

## Learning Principles

- Attempt problems independently before asking AI for help.
- Understand and explain every important piece of code.
- Use AI as a learning assistant, not a replacement for problem-solving.
- Record progress, mistakes, and lessons learned.
- Review and reinforce concepts through independent exercises.
